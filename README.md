# 水电站机组运行检修管理平台

面向电站台账、机组运行、调速励磁、主变与闸门、大坝渗流位移监测、机组检修与发电计划的一体化水电站运行检修管理平台。

这是一个**纯前端**管理平台：Vue 3 + Vite + TypeScript，仓库里没有后端服务。业务数据由
`frontend/src/data/` 下的本地数据层提供：首次打开用示例数据播种，之后的登记、筛选与状态流转
结果都持久化在浏览器 `localStorage` 里，刷新或重开浏览器都还在。dev server 已关掉自动打开页面，
启动后按终端打印的地址手工打开。

## 目录结构

```text
.
├── frontend/                 Vue 3 + Vite + TypeScript 前端（唯一运行单元）
│   ├── src/views/            每个业务模块一个页面
│   ├── src/api/local-service.ts   本地数据服务：列表、筛选、动作流转、导出
│   ├── src/data/             模块元数据 / 示例数据 / localStorage 持久化
│   ├── src/stores/           会话与筛选状态
│   └── vite.config.ts        dev server 配置（open: false，无 /api 代理）
├── .gitignore
└── docker-compose.yml
```

## 启动

```bash
cd frontend
npm install
npm run dev
```

前端默认监听 `http://127.0.0.1:5173/`，dev server 不会自动打开浏览器，需要自己访问。

生产构建：

```bash
cd frontend
npm run build
```

## 约定

- 每个模块的页面在 `frontend/src/views/<模块>/index.vue`，页面只负责渲染，读写统一走
  `frontend/src/api/local-service.ts`。
- 字段、状态、动作与流转目标集中在 `frontend/src/data/modules.ts`；示例数据在
  `frontend/src/data/seed.ts`。
- 状态流转只允许在 `local-service.ts` 里改，页面组件不做业务判断。
- 想回到初始数据：清掉浏览器里 `hydropower-plant-om:entries` 这一项，或调用 `resetModule(模块)`。

## 主变试验 → 投运链路（真落库）

主变压器链路不走通用动作，业务规则集中在 `frontend/src/api/transformer-service.ts`，
台账、告警、消缺待办、发电计划容量在同一次写库事务里提交（`commitState`）：

- **提交试验**：试验结论（合格/不合格）、试验日期、试验人随油温/绕组温度/油位/瓦斯保护读数
  一次写进主变压器台账；刷新或返回页面读到的是同一份，不会退回“待试验”。
- **覆盖语义**：同一台主变只保留最后一次试验结论，按提交覆盖（不叠加台账行）；
  不合格时生成的备品备件消缺待办同样按主变 upsert（一份，不重复叠加），合格复测自动关闭并留关闭痕迹。
- **告警决定能否投运**：油温 > 85℃ 或瓦斯保护不是“正常投运/正常”时，出不了“合格”结论；
  有未撤销的有效告警时结论照落但不允许投运，必须先“撤销告警”（复测恢复后），撤销后主变自动转回运行中。
- **告警留痕**：发布/撤销都是 append-only 记录，撤销只是把状态改为“已撤销”并记录撤销人、时间、原因，不删除。
- **容量回写**：主变状态是唯一事实源，每次变动都重算并写入发电计划每一行的
  `可用主变台数` 与 `可用主变容量(MVA)`，两处口径强制一致，不会“一边投运一边还算停运”。
- **纸质报告回填**：早期只有纸质报告、没有试验人的存量记录，试验人统一补“纸质报告未署名”
  （不猜具体人名），并用 `资料来源` 标注“纸质报告回填 / 系统升级回填”，可追溯。
- **存量迁移**：localStorage 按 `__version` 版本号迁移，保留原有编号、数组顺序与既有结论，不被新版重排；
  告警态主变补录一条有效告警，发电计划迁移时即与主变台账对齐；存量消缺待办按登记时间排序，缺来源项标注“待核实”。
- **断线/超时重试**：写库失败自动重读最新状态后重放一次；仍失败返回明确原因
  （存储已满 / 存储不可用 / 序列化失败），绝不做假成功。
- **导出**：主变台账、告警记录、消缺待办、发电计划均从同一持久层导出，字段与页面台账逐行一致
  （CSV 对逗号/引号/换行做了转义）。

